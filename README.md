# Simple JS Calculator - Entri Elevate Assignment

This is a simple web-based calculator designed as part of the **Entri Elevate Full Stack Development** course (Module: Javascript, Assignment No: 7).

## 🚀 Objective
To design and implement a calculator that performs basic arithmetic operations and includes specialized functions for Square and Cube calculations.

## 🛠️ Features
- **Basic Arithmetic:** Addition, Subtraction, Multiplication, and Division.
- **Advanced Functions:** Calculate the Square (x²) and Cube (x³) of a given number.
- **Responsive Design:** A clean and user-friendly interface built with CSS.
- **Error Handling:** Displays an error message for invalid mathematical expressions.

## 📂 Project Structure
The project is organized into separate files for better maintainability:
- `index.html`: Contains the structure and layout of the calculator.
- `style.css`: Contains the styling and design elements.
- `script.js`: Contains the logic for mathematical operations and functions.

## 💻 Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

## 📖 How to Use
1. Enter the numbers using the on-screen buttons.
2. Choose an operation (+, -, *, /).
3. Press `=` to see the result.
4. Use the `x²` button to find the square and `x³` to find the cube of the current number on the screen.
5. Press `C` to clear the display.
